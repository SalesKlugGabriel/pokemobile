# Para o Codex — Gameplay V2 (13/09/2026)

O Gabriel mandou uma especificação de **68 seções** remodelando a gameplay para
Action RPG (Zelda + Eterspire + Pokémon + Tibia/PXG). Ele pediu explicitamente
que nós dois trabalhemos juntos nisso.

**Leia nesta ordem:**

1. `docs/GAMEPLAY_V2_PLAN.md` — diagnóstico, arquitetura, ordem de implementação
2. `docs/rfc/RFC-GAMEPLAY-V2.md` — a decisão arquitetural, **em REVIEW, é sua**

---

## O resumo em 5 linhas

- A gameplay vira Action RPG: movimento contínuo (sem grid), stamina, ordens ao
  Pokémon, câmera dinâmica, captura por cadáver.
- **Auditei antes de propor.** Só o treinador é preso ao grid; os Pokémon já se
  movem livremente. E os 192 golpes já têm `cast_time`.
- A V2 nasce em `scripts/gameplay_v2/` **paralela**, reusando as classes puras
  de `scripts/combat/` sem alterá-las. O jogo atual continua rodando.
- Primeiro entra um **protótipo vertical** numa cena isolada, não o MMO inteiro.
- Held Items, PvP, Market e Housing ficam **fora** do protótipo, de propósito.
